</p>◈ THE DECAN XMD EXPERIENCE
DECAN XMD is a terminal-first WhatsApp automation runtime designed around a simple idea:
No unnecessary dashboard. No unnecessary browser layer. Just the bot.

The runtime is designed for hosting panels, VPS environments and command-line deployments where the terminal is the control center.

⌁ COMMAND ECOSYSTEM

◉ SESSION ARCHITECTURE
DECAN XMD uses persistent local session storage so a successfully authenticated device can be restored when the runtime restarts.

Keep your authentication/session data private. Never commit credentials, tokens or private session files to GitHub.

◈ HOSTING PANEL MODE
DECAN XMD is intended to work cleanly with Node.js hosting panels.

Recommended startup configuration:
Startup File: index.js
Typical runtime:
Node.js
npm install
node index.js
The runtime does not require a web port just to operate as a WhatsApp bot.
