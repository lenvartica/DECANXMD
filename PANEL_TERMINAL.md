# DECAN XMD — Terminal-Only Hosting Panel

DECAN XMD is configured for hosting panels where the application is controlled from the terminal.

## Start

```bash
npm install
npm start
```

or:

```bash
npm run terminal
```

The application starts `index.js`, initializes the WhatsApp runtime, and asks for the phone number directly in the terminal.

You can also provide the number without an interactive prompt:

```bash
PAIR_PHONE=2547XXXXXXXX npm start
```

For Windows panels:

```bat
set PAIR_PHONE=2547XXXXXXXX
npm start
```

## Important

- The `public/` directory has been completely removed.
- No Express web server is started.
- No dashboard URL is created.
- No browser panel is required.
- `index.js` is the primary panel entrypoint.
- `terminal.js` is only a compatibility launcher and forwards to `index.js`.
- Pairing codes are generated by WhatsApp/Baileys; `DECANXMD` is the bot branding, not a selectable WhatsApp pairing code.

## Terminal-only pairing fix

The hosting-panel entrypoint is `index.js`. It does not start Express or a web dashboard and does not require a `public/` directory.

Use the panel startup file:

```text
index.js
```

The bot will prompt for the WhatsApp number in the panel console. For panels without interactive stdin, set:

```text
PAIR_PHONE=2547XXXXXXXX
```

The pairing code is generated by Baileys/WhatsApp and printed directly in the terminal.
